# 전환기보드 담임 (PWA)

담임 선생님이 **폰으로 우리 반 칠판에 공지를 올리고 학생을 호출**하는 앱입니다. (전환기보드 = 혜원여중 3학년 전자칠판)

- 기능은 **호출**(학생 여럿을 한 번에, 자주 쓰는 메시지, 칠판이 확인했는지) · **공지**(긴급 공지 노란 띠 · 담임 한 마디)뿐입니다.
- 폰·폴드(커버/펼침)·태블릿 어디서나 쓰는 웹앱입니다. 홈 화면에 추가하면 앱처럼 열립니다. 라이트/다크 자동.
- **열쇠(교사용 주소)는 이 저장소에 없습니다.** 처음 한 번 «교사용 주소»를 붙여 넣거나 «연결 링크»를 누르면 그 폰에만 저장됩니다.
- 서버는 구글 Apps Script(전환기보드 `TeacherApi.js` 의 `doPost`) — 열쇠가 있어야만 열립니다.

## 파일
`index.html`(앱 전체, v1.1.0) · `sw.js`(서비스워커: 화면 뼈대만 저장, 서버 요청은 가로채지 않음) · `manifest.webmanifest` · `icons/`

## 연결 링크 만드는 법
`https://arete929.github.io/yucall-teacher/#c=<코드>` — 코드는 `base64url(JSON {"u":"<…/exec>","k":"<교사 열쇠>"})`.
전환기보드 관리자 화면의 「⑪ 담임 휴대폰 앱」 카드가 만들어 줍니다. 링크를 열면 주소줄에서 열쇠가 바로 지워집니다.
